## SNIPPETS FROM EXISTING CODE TO REFERENCE

### CertificateController::generateCertificateNumber (reuse this!)
```php
private function generateCertificateNumber(string $organizationId, string $pattern): string
{
    return DB::transaction(function () use ($organizationId, $pattern) {
        $sequence = CertificateSequence::lockForUpdate()
            ->firstOrCreate(
                ['organization_id' => $organizationId, 'pattern' => $pattern],
                ['next_value' => 1]
            );

        $value = $sequence->next_value;
        $sequence->increment('next_value');

        $width = substr_count($pattern, '#');
        $paddedValue = str_pad($value, $width, '0', STR_PAD_LEFT);

        $number = str_replace('####', $paddedValue, $pattern);
        $number = str_replace('YYYY', date('Y'), $number);

        return $number;
    });
}
```

### CertificateTemplateController::isTemplateLocked (pattern for checking references)
```php
private function isTemplateLocked(CertificateTemplate $template): bool
{
    return Event::where('template_id', $template->id)
        ->orWhere('email_template_id', $template->id)
        ->exists();
}
```

## WHAT NOT TO DO (COMMON HALLUCINATIONS)

| ❌ Don't Do | ✅ Do Instead |
|-------------|---------------|
| Add `middleware(['jwt.auth', 'jwt.endpoint'])` to routes | Leave routes WITHOUT auth middleware (deferred) |
| Create new services (EmailService, QrService) | Use existing `PdfService` only; email/QR are deferred |
| Implement `created_by` author-scoping logic | Just save `$request->attributes->get('jwt_claims.sub')` if present; scoping is middleware's job |
| Add `cert.*` permission checks | No permission checks at all — auth is deferred |
| Use `PUT` for updates | Use `PATCH` for partial updates (spec §3.2) |
| Return base64 PDF in JSON | PDF endpoints return raw binary (spec §3.7) — but Events/Attendees don't have PDF endpoints |
| Generate certificate numbers without `CertificateSequence` | ALWAYS use `generateCertificateNumber` (atomic) |
| Default `certificate_number_pattern` | It's REQUIRED per spec — validate presence and `####` |
| Allow `auth_process` template type | Only `certificate` and `email` types (spec §2.2) |
