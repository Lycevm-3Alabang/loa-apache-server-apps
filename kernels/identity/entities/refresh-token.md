# RefreshToken Entity

## Identity Kernel

### Purpose

Persists refresh tokens in the database so they can be validated, rotated, and revoked per the token lifecycle rule.

### Attributes

| Attribute | Type | Constraints | Description |
|-----------|------|-------------|-------------|
| id | UUID | PK | Unique identifier |
| user_id | UUID | FK, required | Associated user |
| jti | string | required, unique | Hashed JWT ID (SHA-256 of the raw `jti` claim) |
| expires_at | timestamp | required | Token expiry (7 days) |
| revoked_at | timestamp | nullable | When the token was revoked |
| replaced_by | UUID | nullable | New token record that rotated this one |
| created_at | timestamp | auto | Creation time |

### Invariants

1. `jti` is stored hashed, never raw
2. Token expires after 7 days (`JWT_REFRESH_TTL`)
3. Refresh tokens are single-use (revoked on every rotation)
4. A revoked or rotated token is permanently rejected
5. A token record is only usable before `expires_at`

### Relationships

- belongsTo User
- hasOne RefreshToken (via `replaced_by`)

### Business Rules

1. **Issue** (on `login()`):
   - Generate refresh token JWT with a `jti` claim
   - Store record: `user_id`, `hash('sha256', jti)`, `expires_at = now + refresh_ttl`
2. **Refresh** (on `refresh()`):
   - Validate JWT signature and expiry
   - Look up record by `hash('sha256', jti)`
   - Reject if record is missing, revoked, or expired
   - Generate a new token pair
   - Revoke the old token (`revoked_at = now`, `replaced_by = new record id`)
   - Store the new token record
3. **Logout** (on `logout()`):
   - Look up record by `hash('sha256', jti)`
   - Mark `revoked_at = now`
4. **Password change**: mark all tokens for the user revoked
5. **Password reset**: mark all tokens for the user revoked
6. **Account locked**: mark all tokens for the user revoked
7. **Account disabled**: mark all tokens for the user revoked
8. **Pruning**: expired or revoked records are purged after 30 days

### Token Generation

The `jti` claim is generated by the JWT service:

```php
$jti = bin2hex(random_bytes(16));
```

The persisted value is a hash of the raw `jti`:

```php
$jtiHash = hash('sha256', $jti);
```

### Factory

```php
RefreshToken::create([
    'user_id' => $user->id,
    'jti' => hash('sha256', $jti),
    'expires_at' => now()->addMinutes(config('jwt.refresh_ttl', 10080)),
]);
```
